Storage

checking…
  • ltf.storage.get(key) — resolves with the value, or null
  • ltf.storage.set(key, value) — store a JSON-compatible value
  • ltf.storage.remove(key) — delete a key
  • ltf.storage.clear() — clear this app's storage only
—

Values must be JSON-compatible (string, number, boolean, null, array, plain object). Functions, DOM nodes, File/Blob and cyclic objects are rejected. Per-value limit: 100 KB. Each app has its own isolated namespace — it cannot read other apps' data. Stored values persist across app/page reloads (reopen this app and press “Get Test Value”).
